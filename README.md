# SAASTest
 Somos a SAAS (Sistema de Agendamento de Atendimento de Saúde), uma startup de tecnologia focada em soluções digitais para a área da saúde. Nosso objetivo é simplificar o agendamento e o atendimento médico, oferecendo praticidade para pacientes e eficiência para profissionais da saúde.
